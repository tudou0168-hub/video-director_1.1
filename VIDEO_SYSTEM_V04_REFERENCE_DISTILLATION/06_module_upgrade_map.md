# 06 Module Upgrade Map

| Reference Class | Existing / Target Module | Upgrade Requirement |
|---|---|---|
| Big Word Impact | `BigKineticTitle` | Bigger Chinese type, keyword highlight, left-zone priority |
| Top Label | `TopSectionLabel` | Always visible per beat, concise English + Chinese context |
| Comparison | `OptionSplitCard` | Compact split, red/green or red/blue semantics, no thick fill |
| Data / KPI | `KPIBigNumberOverlay`, `ScoringDimensionPanel` | Big number first, chart second, explanation last |
| Evidence | `ProofScreenshotOverlay`, `DetailsTableOverlay` | Prefer real screenshot, wireframe fallback marked as proof placeholder |
| Workflow | `ThreeStepPipeline`, `APIHandoffCard` | Three steps max per frame, line-based arrows |
| Platform / Private Domain | `PhoneIntegrationCards` | Small floating cards, do not cover face or subtitles |
| Concept Teaching | `TermExplainerPanel` | One term, one plain-language definition, one use case |
| CTA | `CTABigEnding`, `CompletionScoreEnding` | One keyword, one free step, one paid result |

## Forbidden Upgrade

Do not make modules bigger by adding solid backgrounds. Make them stronger through type scale, glow line, contrast, and timing.
