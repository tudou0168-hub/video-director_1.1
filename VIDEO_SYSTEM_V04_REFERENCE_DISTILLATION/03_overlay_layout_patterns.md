# 03 Overlay Layout Patterns

## Safe Zones

- Face safe zone: never cover eyes, mouth, or main facial contour.
- Subtitle safe zone: bottom fixed area, maximum two Chinese lines.
- Main title zone: usually left 35%-45% when the speaker is left or right weighted.
- Proof zone: center-right or side panel, never under subtitles.

## Layout Patterns

### Left Big Title + Right Speaker

Use for hooks and painful truths. The title is the product; HUD is secondary.

### Split Comparison

Use for old path vs new path. Keep each side compact, with red/blue or red/green semantic contrast.

### Floating Proof Stack

Use for screenshots, data tables, or product evidence. The stack should be transparent wireframe unless a real screenshot is shown.

### Step Pipeline

Use for process teaching. Three steps maximum on one frame.

### CTA Ending

Use a large result phrase, keyword, and one next action. Avoid dense explanation at the end.
