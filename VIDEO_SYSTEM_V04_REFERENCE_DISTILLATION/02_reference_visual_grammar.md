# 02 Reference Visual Grammar

## What Codex Must Learn

Codex must learn the abstract grammar behind the references, not copy one screenshot.

1. One frame has one visual center.
2. Large Chinese type carries the emotion and result.
3. Thin line frames carry structure.
4. Semantic color carries meaning.
5. Screenshots and tables prove the claim.
6. Every overlay must map to one spoken sentence.
7. Overlays enter, stay active, and exit with the voice rhythm.

## Big Word Grammar

- Font size: `88-140px` for 1080p horizontal frames.
- Position: left empty area first; avoid face and bottom captions.
- Shape: 1-3 short lines, keyword highlighted.
- Motion: impact entry, small active breathing, clean exit.

## Evidence Grammar

- Evidence is not decoration.
- It must answer: what changed, what was proved, or what the viewer can copy.
- Fake platform UI is forbidden. Use abstract wireframes if no real screenshot exists.

## Failure Conditions

- Card looks like a thick dashboard.
- Bottom subtitle becomes the only information layer.
- Text is too small to read on mobile.
- Overlay stays on screen after the spoken point ends.
- The frame has many small boxes but no main idea.
