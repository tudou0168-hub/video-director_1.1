# 07 Reference Scoring Rubric

Score every snapshot before render.

| Item | Points |
|---|---:|
| Has one clear visual center | 15 |
| Large Chinese title/number is readable | 15 |
| TopSectionLabel exists | 10 |
| StepBadge/status exists when the beat needs progress | 10 |
| HUD is transparent line-frame, not solid dashboard | 15 |
| Face and subtitles are not blocked | 15 |
| Visual maps to the current spoken sentence | 10 |
| Looks like short-video creator packaging | 10 |

Render threshold: `85/100`.

If a frame scores below 85, tune layout, font size, transparency, and component density before rendering.
