# 08 Codex Component Upgrade Prompt

Use this prompt before modifying components:

```text
Do not optimize the whole video system.

Take the current storyboard beat and choose one reference class:
Big Word Impact, Chart Explanation, Comparison Card, Comment/Evidence, or Product/Case Proof.

Upgrade only the matching component.

Rules:
- Chinese viewer-facing text first.
- No bilingual subtitles.
- No thick dashboard cards.
- HUD background alpha must stay between 0.04 and 0.12.
- Use line frames, glow borders, large type, semantic color, and motion timing.
- Every module needs entry, active, and exit behavior.
- Snapshot first. Do not render until the keyframes score 85+.
```
