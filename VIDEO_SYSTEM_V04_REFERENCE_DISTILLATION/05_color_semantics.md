# 05 Color Semantics

Use color as meaning, not decoration.

| Color | Meaning | Use |
|---|---|---|
| Blue | Tool, system, information, process | Hermes, Codex, data flow |
| Green | Done, method, positive result | completed step, saved time |
| Yellow | Money, value, paid result, opportunity | paid product, result promise |
| Red | Error, risk, old path, warning | wrong effort, wasted time |
| Purple | Multi-agent, assistant layer, optional intelligence | agent collaboration |

## Rule

One visual center can have one dominant semantic color plus one accent. Do not turn the frame into a rainbow dashboard.
