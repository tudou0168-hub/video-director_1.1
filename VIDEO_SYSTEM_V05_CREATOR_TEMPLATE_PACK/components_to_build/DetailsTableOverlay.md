# DetailsTableOverlay

## Purpose

Reference-grade Creator Overlay component for HyperFrames talking-head videos.

## Contract

- Plain HTML/CSS/GSAP implementation.
- Transparent line-frame HUD when a panel is needed.
- Entry / active / exit motion required.
- Chinese subtitles only when subtitle text is involved.
- Must avoid face and subtitle safe zones.

## Snapshot Acceptance

- Mobile readable.
- Clear visual hierarchy.
- No thick Dashboard fill.
- Bound to a sentence or beat, not permanent decoration.
