# 09 Snapshot Acceptance Rubric

## Per-Snapshot Questions

1. Is there a clear large title/number?
2. Is TopSectionLabel visible?
3. Is StepBadge/status visible?
4. Is HUD line-based and transparent?
5. Is text readable on mobile?
6. Does it look like creator short-video packaging?
7. Does it avoid PPT / Dashboard / meeting-caption feel?

If questions 1, 2, 4, or 6 fail, redo the frame.

## Required Snapshots

`1s / 6s / 14s / 24s / 32s / 40s / 48s / 56s`.
