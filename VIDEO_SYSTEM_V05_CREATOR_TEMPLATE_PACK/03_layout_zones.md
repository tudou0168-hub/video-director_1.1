# 03 Layout Zones

This inherits `VIDEO_SYSTEM_FINAL_CREATOR_OVERLAY/05_layout_safe_zones.md`.

## Default Talking-Head Assumption

- Person is center-right.
- Left side is primary title zone.
- Right top is StepBadge.
- Bottom is Chinese subtitle.
- Center-left carries process cards.
- Right side carries proof screenshots only when it does not cover the face.

## One Primary Visual Rule

Each keyframe has one primary visual center:

- BigKineticTitle
- MegaNumber
- OptionSplitCard
- ThreeStepPipeline
- DetailsTableOverlay
- MultiAgentPanel
- ProofScreenshotOverlay
- CTABigEnding

Other elements are support only.
