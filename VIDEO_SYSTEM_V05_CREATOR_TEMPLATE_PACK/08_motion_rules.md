# 08 Motion Rules

- Static snapshot likeness comes before smooth video.
- Entry starts 0.15s before the sentence where possible.
- Active motion must be semantic: glow, border pulse, node highlight, count-up.
- Exit 0.2-0.4s after sentence end.
- No random flicker, heavy glitch, or decorative particle clutter.
- One primary visual group moves at a time.
