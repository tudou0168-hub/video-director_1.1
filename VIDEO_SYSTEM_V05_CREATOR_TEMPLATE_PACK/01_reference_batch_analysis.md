# 01 Reference Batch Analysis

## Shared Traits

- The video is not "HUD effects"; it is Creator Overlay Packaging.
- TopSectionLabel and StepBadge give every frame a navigation system.
- Large typography and numbers are primary subjects, not decorations.
- Screenshots and tables act as proof, not background filler.
- Transparent line frames keep the talking-head video visible.
- Every 5-8 seconds changes the primary visual module.

## Template Analysis

| Template | Reference Trait | Best Use | Fail Condition |
|---|---|---|---|
| Completion Score Ending | Big score, final state, next episode cue | Summary, CTA | Only small text CTA |
| API Key / Handoff Card | Left-right handoff and DONE status | Install, deploy, API config | Fake API screen |
| Phone Integration Cards | App cards and phone/service labels | Private traffic, distribution | App icons become clutter |
| Viral Source Scan | Horizontal source carousel | Trend mining, Hermes source scan | Tiny thumbnails |
| Source Scoring Dashboard | Source / timeline / scoring info | Intelligence filtering | Thick dashboard card |
| Dimension Scoring List | Big number + scoring list | Topic scoring, diagnosis | No dominant number |
| Details Table Overlay | Big table proof | Obsidian, Feishu, database | Screenshot unreadable |
| Multi-Agent Collaboration | Formula and role cards | Hermes/Codex/Claude Code teamwork | Too many equal cards |
| Term Explainer | Series number + term | Agent concept teaching | Like lecture slide |
| Final Agent Chart | Trend chart and multiplier | Efficiency/cost trend | Chart too small |

## Implementation Notes

- Use plain HTML/CSS/GSAP.
- Bind each visual module to one sentence or beat.
- Use real screenshots where possible.
- Use `TODO_ASSET_REQUIRED` when proof is missing.
