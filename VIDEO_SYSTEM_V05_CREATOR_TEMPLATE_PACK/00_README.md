# V0.5 Creator Template Pack

V0.5 consolidates the reference-image template library into executable rules for HyperFrames talking-head creator videos.

## Principles

- Static snapshots first, render later.
- One keyframe has one primary visual center.
- HUD backgrounds are nearly transparent.
- Line frames, glow borders, and large Chinese typography carry the image.
- Chinese subtitles only. No bilingual subtitles in this project.
- Real screenshots are preferred; no fake platform UI.
- Media outputs are local artifacts and must not be committed.

## Core Templates

1. Completion Score Ending
2. API Key / Handoff Card
3. Phone Integration Cards
4. Viral Source Scan
5. Source Scoring Dashboard
6. Dimension Scoring List
7. Details Table Overlay
8. Multi-Agent Collaboration
9. Term Explainer
10. Final Agent Chart

## Required Loop

```text
rules -> storyboard -> timeline -> snapshot -> score -> tune -> render
```
