# 08 Creator Overlay Templates

## Template Rules

每个模板必须包含 TopSectionLabel、StepBadge 或状态徽章、BottomChineseSubtitle，并至少包含一个主视觉模块。

## Templates

| Template | Use | Visual |
|---|---|---|
| COMPLETION_SCORE_ENDING | 总结、完结、下期预告 | 左侧大数字 + 右侧状态按钮 |
| API_HANDOFF_CARD | API Key、配置交接 | 黑金线框 -> 蓝色线框 -> DONE |
| PHONE_INTEGRATION_CARDS | 手机端、私域接入 | 大标题 + 3 个 App 线框卡 |
| VIRAL_SOURCE_CAROUSEL | 爆款信源 | 横向封面卡 + 播放量 |
| SOURCE_SCORING_DASHBOARD | 情报评分 | 指标组 + 信息卡，必须透明线框 |
| DIMENSION_SCORING_LIST | 维度筛选 | 大数字 + 列表 + 截图 |
| DETAILS_TABLE_OVERLAY | 选题库、表格 | 大标题 + 透明行列表 |
| MULTI_AGENT_COLLABORATION | 多 Agent 协作 | 角色卡 + 公式 + 分工 |
| TERM_EXPLAINER_PANEL | 术语解释 | 编号 + 大标题 + 右侧解释 |
| FINAL_AGENT_CHART | 趋势结论 | 大标题 + 柱状图 |
| OPTION_SPLIT_CARD | 两种路径 | 左右线框卡 + OR |
| THREE_STEP_PIPELINE | 三步流程 | 三个节点 + 箭头 + 当前高亮 |

## Fail Conditions

- 变成厚重 Dashboard。
- 没有大标题或大数字。
- 所有信息缩在角落。
- 底部字幕代替主视觉。
