# Reference Style Definition

目标不是普通 HUD，也不是厚重仪表盘，而是知识博主口播包装系统：

```text
暗色口播背景 + 透明线框 HUD + 大中文标题 + 顶部栏目 + StepBadge + 纯中文字幕
```

## 画面特征

- 人物脸部清楚，背景略暗。
- 文字和信息图层也是主体，不只是装饰。
- 左上角有栏目标签，右上角有步骤或状态。
- 主视觉字号明显大于底部字幕。
- 每 5-8 秒切换一次主视觉。

## 必须避免

- 厚重黑卡片。
- 大面积蓝色玻璃底。
- 小字堆满角落。
- 底部字幕承担全部信息。
- 双语字幕。
- 会议字幕感、PPT 感、Dashboard 感。

## 一屏一个主视觉

每个关键帧只允许一个主视觉中心。其他元素只做辅助。

主视觉可以是：

- BigKineticTitle
- MegaNumber
- OptionSplitCard
- ThreeStepPipeline
- DetailsTableOverlay
- MultiAgentPanel
- ProofScreenshotOverlay
- CTABigEnding
